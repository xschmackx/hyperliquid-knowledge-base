# SHELF — OBSERVATION REGISTER

This page names the register shelf. Filing vocabulary stays in `REGISTER-RULES.md`. This page does not change those statuses. It does not fill the register.

---

## Shelf

| Field | Value |
|-------|--------|
| Shelf | Observation register |
| Corpus path | `register/` |
| Question this shelf answers | What was seen to exist or change, and when was it checked? |

The register is not a `pages/` shelf. Entries are observations. Accepted corpus pages stay under `pages/`.

---

## In scope

| Slot | About |
|------|--------|
| Entry files | One observation per file in `register/`. Filename matches the id: `R-HLKB-NNN.md`. |
| Index | Optional `register/README.md` listing filed ids. The README is a map, not an observation. |
| Cross-links | An entry may name `pages/` paths in the `pages` field. That does not rewrite the page. |

Status words, required fields, and the rule that an observation does not create work remain exactly as `REGISTER-RULES.md` states: `observed`, `changed`, `affects-page`, `noted`.

---

## Out of scope

| Topic | Where it belongs |
|-------|------------------|
| Accepted facts about the protocol, markets, fees, risk, or APIs | `pages/` |
| Filling the register | Not this rule |
